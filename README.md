# DSA Patterns Cheat Sheet

A GitHub-ready version of the supplied **DSA Patterns Cheat Sheet**.

## Rule
**One question daily.**

The source is organized as a sheet with the columns **Pattern, Question, Link 1, Link 2, Link 3**. The repository keeps that same structure while making each pattern easy to practice and track.

2. Fast & Slow Pointers

8. Stack

## Source

Built from the supplied 4-page PDF. The PDF itself shows a spreadsheet-style tracker with green question rows and highlighted pattern headings; this repository preserves the pattern/question/link organization rather than replacing it with a different syllabus.
